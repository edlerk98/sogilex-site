# Sogilex

The Sogilex company site, served at https://sogilex.com/ via GitHub Pages.

- Plain HTML and CSS, no build step, no cookies, no analytics.
- Fonts are self-hosted in `assets/fonts` (SIL Open Font License).
- Products live on their own subdomains, e.g. Savepoint Atlas at https://atlas.sogilex.com/.
- `[CONTACT EMAIL]` is a placeholder to fill in.
